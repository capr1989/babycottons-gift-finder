# Palette update

The owner requested a white background (`#ffffff`) and text `#a7c2c5`. These are the section defaults and are applied in its page-template instance. Panels and product cards also use white. Global theme styles remain unchanged.

Focus outlines and interactive borders use the darker `#567477` so control boundaries remain distinguishable. Selected filters retain their border/weight cues.

Text contrast for `#a7c2c5` on white is approximately **1.88:1**, below WCAG AA requirements for both normal and large text. This requested palette is an explicitly documented accessibility limitation, not a passing contrast check. A darker text color should be considered before launch.

The public template remains free of live product selections. Catalog changes must be reflected through configured product blocks or an owner-approved source collection. Adding the eligibility tag alone does not populate an unconfigured block list.
