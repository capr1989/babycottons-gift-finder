# Compatibility audit — public summary

The inspected installation uses Prestige 4.7.2 with both traditional Liquid page templates and existing JSON page templates. The extension uses a JSON template with a dedicated section, keeping the theme layout, header and footer intact. Theme typography is inherited; local colors and component classes do not change global settings.

Catalog review established that gift eligibility tags alone do not establish category, age suitability or variant availability. Existing broad pajama tags also occur on accessories and underwear. The classifier accounts for those distinctions and excludes unknown or conflicting mappings.

Observed size formats include NB, month values suffixed m and toddler values suffixed t. Ambiguous labels and numerical jewelry sizes are not inferred as child ages. The exact operational audit, catalog snapshot, theme identifiers and installation records are intentionally kept out of this public repository.

Only custom code is distributed here; no proprietary theme files were copied.
